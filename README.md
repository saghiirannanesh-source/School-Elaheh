# دنیای الهه 🌸🦋

نسخه‌ی اولیه‌ی وب‌سایت دیجیتال دبستان و پیش‌دبستانی دخترانه الهه.

## ویژگی‌های این نسخه

- طراحی فارسی و RTL
- هویت بصری کتاب + پروانه
- صفحه‌ی اصلی مدرن و واکنش‌گرا
- معرفی مدرسه
- دنیای یادگیری
- مجله‌ی الهه
- گالری نمونه
- بخش والدین
- بازی آموزشی اولیه بدون نیاز به حساب کاربری
- ناوبری موبایل و دسکتاپ
- انیمیشن‌های نرم با پشتیبانی از `prefers-reduced-motion`
- دکمه‌ی بازگشت به بالای صفحه و نشانه‌گذاری بخش فعال منو
- معماری ساده و قابل توسعه برای ورود، پروفایل، پنل مدیریت و سیستم امتیاز در آینده
- قابل انتشار مستقیم روی GitHub Pages بدون build step

## وضعیت قابلیت‌های حساب کاربری

در این نسخه هیچ ثبت‌نام، ورود یا ذخیره‌ی امتیاز شخصی وجود ندارد. جایگاه این قابلیت‌ها در معماری آینده در نظر گرفته شده تا بعداً بدون بازطراحی کامل سایت بتوانیم احراز هویت، پروفایل، سیستم امتیاز، نشان‌ها، درخت پیشرفت و پنل‌های اختصاصی را اضافه کنیم.

## انتشار روی GitHub Pages

از تنظیمات مخزن، بخش **Pages** را روی شاخه‌ی `main` و پوشه‌ی `/ (root)` قرار دهید.

## نقشه‌ی توسعه‌ی آینده

- احراز هویت و ورود امن
- حساب دانش‌آموز و والد
- پروفایل
- امتیاز و نشان‌ها
- درخت پیشرفت
- پنل مدیریت محتوا
- بازی‌های بیشتر
- اطلاعیه‌ها و تقویم پویا
- اتصال به بک‌اند و پایگاه داده
